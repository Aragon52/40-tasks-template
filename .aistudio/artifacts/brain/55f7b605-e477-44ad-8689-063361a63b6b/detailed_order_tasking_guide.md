# Admin Guide: Order Tasking & Assignment Methods | Admin လမ်းညွှန်: အော်ဒါတာဝန်ပေးခြင်းနှင့် နည်းလမ်းများ

This guide is exclusively for administrators and moderators to manage user order tasking and assignment methods.

---

## 1. Overview of Order Tasking (အော်ဒါတာဝန်ပေးခြင်း အကျဉ်းချုပ်)

### English
The **Order Tasking** module in the Admin Portal allows administrators to create, manage, and assign retail order worksheets to users. Admins have full control over templates, customized orders, pricing, and active task progress.

### မြန်မာဘာသာ
Admin Portal ရှိ **Order Tasking** မော်ဂျူးသည် အသုံးပြုသူများအတွက် လက်လီအော်ဒါစာရွက်စာတမ်းများ (Worksheets) ဖန်တီးခြင်း၊ စီမံခန့်ခွဲခြင်းနှင့် တာဝန်ပေးအပ်ခြင်းတို့ကို လုပ်ဆောင်နိုင်စေပါသည်။ Admin များအနေဖြင့် နမူနာပုံစံများ၊ စိတ်ကြိုက်အော်ဒါများ၊ ဈေးနှုန်းများနှင့် တာဝန်လုပ်ဆောင်ဆဲ အခြေအနေများကို အပြည့်အဝ ထိန်းချုပ်နိုင်သည်။

---

## 2. Task Assignment Methods (တာဝန်ပေးအပ်မှု နည်းလမ်းများ)

Administrators can utilize the following methods when assigning tasks to users:

### A. AI Edge Assignment (AI စနစ်ဖြင့် တာဝန်ပေးအပ်ခြင်း)
*   **English**: An automated dynamic progression method where order prices and profits are calculated automatically based on the user's wallet balance (e.g., Order #1 adjusts $18 to $37, subsequent orders scale accordingly with 5%-13% profit).
*   **မြန်မာဘာသာ**: အသုံးပြုသူ၏ လက်ကျန်ငွေအပေါ် မူတည်၍ အော်ဒါဈေးနှုန်းနှင့် အမြတ်ငွေများကို အလိုအလျောက် တွက်ချက်ပေးသည့် စနစ်ဖြစ်သည်။

### B. Template-Based Assignment (နမူနာပုံစံများဖြင့် တာဝန်ပေးအပ်ခြင်း)
*   **English**: Assigning pre-configured product templates (such as Template M-1, C-1, etc.) containing fixed sets of retail items with predefined prices and commissions.
*   **မြန်မာဘာသာ**: သတ်မှတ်ထားသော ဈေးနှုန်းနှင့် ကော်မရှင်များပါဝင်သည့် ကြိုတင်ပြင်ဆင်ထားသော ကုန်ပစ္စည်း နမူနာပုံစံများကို တာဝန်ပေးအပ်ခြင်း ဖြစ်သည်။

### C. Custom Assignment (စိတ်ကြိုက်တာဝန်ပေးအပ်ခြင်း)
*   **English**: Manually selecting specific products and entering customized prices, quantities, and profit margins for a specific user worksheet.
*   **မြန်မာဘာသာ**: သတ်မှတ်ထားသော အသုံးပြုသူအတွက် ကုန်ပစ္စည်းများကို ကိုယ်တိုင်ရွေးချယ်ပြီး စိတ်ကြိုက်ဈေးနှုန်း၊ အရေအတွက်နှင့် အမြတ်ငွေများကို သတ်မှတ်ပေးခြင်း ဖြစ်သည်။

### D. Semi-Auto Creation (တစ်ပိုင်းအလိုအလျောက် ဖန်တီးခြင်း)
*   **English**: A streamlined assignment method where the administrator defines only the desired total value and price parameters, and the system automatically generates and fills the orders accordingly.
*   **မြန်မာဘာသာ**: Admin မှ လိုချင်သော တန်ဖိုးနှင့် ဈေးနှုန်း ကန့်သတ်ချက်များကိုသာ သတ်မှတ်ပေးပြီး၊ စနစ်မှ အော်ဒါများကို အလိုအလျောက် ဖြည့်စွက်ဖန်တီးပေးသည့် နည်းလမ်းဖြစ်သည်။

---

## 3. Managing Ongoing Tasks & Adjustments (လုပ်ဆောင်ဆဲ တာဝန်များကို စီမံခန့်ခွဲခြင်းနှင့် ချိန်ညှိခြင်း)

### English
*   **In-Progress Adjustments**: Administrators and moderators can edit, adjust, or update all details (such as prices, profits, and upcoming product sequences) for ongoing tasks (**Order in progress**) while the user is actively working on them.
*   **Real-time Control**: This ensures administrators retain full dynamic flexibility over user worksheets at any stage of completion.

### မြန်မာဘာသာ
*   **လုပ်ဆောင်ဆဲ အခြေအနေတွင် ပြင်ဆင်ခြင်း**: Admin များနှင့် Moderator များအနေဖြင့် အသုံးပြုသူမှ အော်ဒါများ လုပ်ဆောင်ဆဲ (**Order in progress**) အချိန်တွင်ပင် လာမည့်အော်ဒါများ၏ အသေးစိတ်အချက်အလက်များ (ဈေးနှုန်း၊ အမြတ်၊ ကုန်ပစ္စည်းအစီအစဉ်များ) ကို အချိန်နှင့်တပြေးညီ ဝင်ရောက်ပြင်ဆင် ချိန်ညှိပေးနိုင်သည်။
*   **အချိန်နှင့်တပြေးညီ ထိန်းချုပ်မှု**: ယင်းက Admin များအား မည်သည့်အဆင့်တွင်မဆို အသုံးပြုသူ၏ worksheet ကို လိုသလို ပြောင်းလဲထိန်းချုပ်နိုင်စွမ်းကို ပေးစွမ်းသည်။
